# 04 — 冲突警告与合并键升级（不等诊断）

**What to build:** 当同一合并键（同一对象 + 同一关系类型，如容器的 `运行于`）上策展值与**当前可用**观测值不等时，控制面立即发出冲突警告，不等待诊断完成。开放冲突可读：策展值、当前可用观测值、合并键。同一合并键上实际由 B 变为 C 时冲突升级并保留演变脉络，不得并行堆叠第二条开放冲突。从空骨架实现 conflict 检测与查询；诊断可尚未完成。

**Blocked by:** 02 — 策展：物理主机、容器与「运行于」；03 — Agent 心跳+快照 → 观测真相与标签匹配

**Status:** ready-for-agent

- [ ] 策展 X 运行于 A、观测 X 运行于 B 时，HTTP 可断言已存在开放冲突警告
- [ ] 警告发出不依赖诊断完成（诊断未就绪也不挡警告）
- [ ] 冲突读取含策展值、可用观测值、合并键
