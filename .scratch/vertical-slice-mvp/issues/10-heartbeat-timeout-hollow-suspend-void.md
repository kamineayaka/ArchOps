# 10 — 心跳超时 → 观测空洞挂起并作废活跃计划

**What to build:** 当相关观测通道心跳超时，原观测变为观测空洞（不可再当可靠「实际」）。若存在开放冲突，冲突挂起（因空洞无法确认实际）而非关闭；任何活跃操作计划作废，不得继续执行指向过期实际的步骤。纯空洞场景下诊断分叉仅允许「恢复观测通道/心跳/核验」类（若本票触及诊断，不得用过期实际猜唯一落点）。这是竖切负面验收之一，须可经 HTTP 主接缝演示。

**Blocked by:** 04 — 冲突警告与合并键升级（不等诊断）；08 — 受控 SSH 逐步执行（fake）与 Redis 计划互斥
