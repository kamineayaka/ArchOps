# 07 — 「修实际回 A」选支与操作计划人审

**What to build:** 已接受的冲突处理人在可读诊断/分叉建议的前提下，选择分支「修实际回 A」（纯修现场），系统跳过草案，生成针对迁回策展宿主的操作计划；处理人审查并批准后，计划才具备执行意图。非处理人不能选支；每冲突同一时间至多一个活跃操作计划；待接受处理人（若存在）不能开计划。从空骨架实现 plan 绑定与人审状态机（尚不执行 SSH）。

**Blocked by:** 05 — 已知悉 + 认领/自任 → 已接受冲突处理人（Must）；06 — 异步诊断（规则必达）+ 可选 LLM 出站 + 敏感读拒绝

**Status:** ready-for-agent

- [ ] 已接受处理人可选择「修实际回 A」；该路径不创建/不要求草案
- [ ] 选支后生成可审查的操作计划（有序步骤对处理人可见）
- [ ] 未人审批准前不能进入执行意图/启动执行
- [ ] 非处理人选支或开计划被拒绝
- [ ] 同一冲突至多一个活跃操作计划
- [ ] 分叉/诊断建议对查看者只读可见；选支权力仅处理人
