# 06 — 异步诊断（规则必达）+ 可选 LLM 出站 + 敏感读拒绝

**What to build:** 冲突警告发出后异步运行诊断，不把警告延迟绑在模型或规则引擎耗时上。诊断结果（含分叉计划建议）对查看者只读可读；规则引擎分叉为 Must；外部模型经 WebClient 仅访问配置的 OpenAI 兼容 HTTPS 白名单，密钥只在控制面，模型不可用时规则兜底且不挡后续选支/人审/执行闭环。诊断载荷不得夹带业务库/客户订单财务等敏感内容；工作台或执行路径上敏感业务读尝试直接拒绝（可 stub/分类器形态）。多副本下诊断任务调度需有界（Redis 队列或等价），Redis 仍不是关系真相 SSOT。

**Blocked by:** 04 — 冲突警告与合并键升级（不等诊断）

**Status:** ready-for-agent

- [ ] 警告后诊断异步触发；可证明警告存在不依赖诊断完成
- [ ] 规则分叉对「实际宿主 ≠ 策展宿主」等至少给出可读的修现场类建议
- [ ] 模型不可用或未配置时仍有规则结果；不阻塞后续闭环能力
- [ ] 若配置 LLM：仅白名单 HTTPS 出站；失败回退规则
- [ ] 敏感业务读尝试返回拒绝（非审批门）
- [ ] 诊断调度在多副本前提下有去重/有界策略（Redis 队列或等价）
