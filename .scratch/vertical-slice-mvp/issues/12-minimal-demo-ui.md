# 12 — 最小演示 UI（冲突→协作→选支→审计划→关单）

**What to build:** 在主链 HTTP API 已可走通关单闭环的前提下，用 React + Ant Design 提供最小可点界面：冲突列表/详情、已知悉或认领/自任、查看诊断/分叉、选择「修实际回 A」、审查并批准操作计划、确认关闭。UI 只调用与验收主接缝相同的公开 HTTP API；不进自动化主接缝，供人工演示/冒烟。不做成完整 xterm 工作台，不另造旁路执行入口。

**Blocked by:** 09 — 观测对齐 → 待确认关闭 → 处理人确认

**Status:** ready-for-agent

- [ ] 可在 UI 列出并打开开放冲突（含两轨值）
- [ ] 可完成已知悉/认领或自任，成为已接受处理人
- [ ] 可查看诊断/分叉并选择「修实际回 A」
- [ ] 可审查并批准操作计划
- [ ] 可在待确认关闭态由处理人确认关闭
- [ ] 无旁路直连/绕过计划冻结的 UI 入口；不要求进 CI 主接缝
