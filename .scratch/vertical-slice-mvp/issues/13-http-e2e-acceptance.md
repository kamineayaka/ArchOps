# 13 — HTTP 主接缝端到端验收（含负面）

**What to build:** 建立以控制面公开 HTTP API（含 Agent ingest）为唯一自动化主接缝的有序验收：策展 A/B 与 X 运行于 A → 快照报运行于 B → 断言冲突警告（可先于诊断完成）→ 认领/自任 →（诊断可读）选「修实际回 A」→ 人审 → SSH fake 执行 → 观测回到 A → 待确认关闭 → 处理人确认。负面至少覆盖：心跳超时挂起+计划作废；敏感读拒绝；未打标不承诺升级链。SSH fake 仅作支撑双，不算第二验收接缝；不以浏览器自动化作为本竖切完成定义。

**Blocked by:** 06 — 异步诊断（规则必达）+ 可选 LLM 出站 + 敏感读拒绝；09 — 观测对齐 → 待确认关闭 → 处理人确认；10 — 心跳超时 → 观测空洞挂起并作废活跃计划
