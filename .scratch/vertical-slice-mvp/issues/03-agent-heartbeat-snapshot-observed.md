# 03 — Agent 心跳+快照 → 观测真相与标签匹配

**What to build:** Host Agent 可向控制面发送心跳，并可附带状态快照（至少含容器列表与标签）；控制面按 `archops.object_id` 匹配策展容器后写入观测真相（如「运行于」某主机），心跳保持观测通道新鲜。调用方可读「实际在哪」，且同屏仍能看到策展值。未打标容器不得承诺冲突升级链（未绑定观测候选 / 身份失联路径）。文档化本切片心跳+快照载荷契约；Python stub 可按契约上报。Postgres 为观测 SSOT；Redis 不作关系真相。

**Blocked by:** 02 — 策展：物理主机、容器与「运行于」
