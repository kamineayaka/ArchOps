# 对象身份：外部 UID 优先，否则策展 ID；容器靠不可变标签

对象同一认定采用分层总纲：有外部权威 UID 时用之（K8s 集群以 kube-system namespace UID 为主键）；否则以策展不可变对象 ID 为主键。物理主机、数据库、K8s 节点以策展 ID 为主，IP/端点/node name/SSH host key 等仅为匹配线索。Docker 容器以策展容器 ID 为主，并要求现场不可变标签（如 archops.object_id）供探测匹配；删重建换宿主仍视为同一对象，位置变化走冲突升级。匹配失败产生未绑定观测候选，禁止静默合并。此规则是冲突升级合并键可用的前提。
