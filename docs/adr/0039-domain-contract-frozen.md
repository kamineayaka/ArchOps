# 领域合同冻结（第二轮 grilling 收束）

截至 ADR-0038，`CONTEXT.md` 与有效 ADR 构成 ArchOps **领域语义**合同（三件套、双轨、冲突协作、心跳/空洞、可达核验、高危三档、AI 权力/能力分界）。ADR-0044 修订**运行时拓扑**（控制面枢纽、执行引擎与 AI 编排层独立进程、工具代发、步骤断言），不重开上述语义。后续变更须显式新 ADR；实现阶段不得用代码习惯悄悄改语义。未决且不挡竖切的项（租户、图 UI 细节、高危正则全表、自我迭代落地）标为 Later。

ADR-0046 只取代上一句里的协作身份：领域没有用户、高级角色、一般角色、归属、已知悉、自任、指派、接受或处理人。K8s 节点职责分类仍称「角色」（ADR-0005）。冲突是否成立、空洞、未绑定、身份失联，以及上列其余冻结语义，不由 ADR-0046 改写。
