# v1 范围主张（待与 ADR-0001 对齐）

（已由 ADR-0014 / ADR-0015 对齐并取代。）

用户标定的 v1 Must：策展写入与 AI 起草草案、三类观测对接、冲突/升级/规范问法展示、未绑定与身份失联、连接工作台、AI 诊断与操作建议（含人审执行）。Later：指标类可观测、AI 自我迭代。约束：去掉全部 AI 后产品不成立，AI 最小 Must 为诊断与操作建议（含人审执行）。

注意：此主张与 ADR-0001「仅关系真相主责交付时产品仍成立；工作台与 AI 可延后」存在张力，须经用户裁定后再升格为有效范围 ADR。
