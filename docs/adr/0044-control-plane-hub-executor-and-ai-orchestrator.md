# 控制面枢纽；执行引擎与 AI 编排层独立进程；工具代发与步骤断言

修订 ADR-0043 的「v1 单进程、拆服务 Later」与 ADR-0041 的「密钥仅存控制面、控制面直连模型」：运行时拆成控制面（规则/真相/权力）、执行引擎、AI 编排层、Host Agent 四进程。控制面是唯一枢纽：计划游标、门禁、诊断取证预算、工具代发都在此。编排层与工作台不直连执行引擎。能力尽量给（资料、只读词汇、步骤详细事件、可写入待审计划的工具目录）；权力不给（选支、人审、发变异、改序列、关单、改白名单）。执行期编排层是观察者，不是序列器。本 ADR 不重开双轨、冲突、冻结计划、人审语义（仍以 CONTEXT 与 ADR-0038 为准）。

## 决议

1. **四进程**：控制面（规则引擎 + 真相 SSOT + 游标 + 代发）；**执行引擎**（独立进程：工具运行、本步步骤断言、SSH/凭证）；**AI 编排层**（独立进程，运维隔离区内：诊断、出计划、失败后再分析）；**Host Agent**（心跳+快照直连控制面写观测，不经执行引擎、不经编排层）。
2. **枢纽协议**：控制面派诊断/失败分析作业给编排层；编排层向控制面请求只读工具并交回分叉/计划（工具序列 + 步骤断言）；控制面一次向执行引擎下发一步；执行引擎返回结构化结果与断言成败；控制面按游标步进或作废，并向编排层推送逐步详细事件。空洞/升级/取消时控制面立刻停止下发并作废在途一步。
3. **工具调用**：全部经控制面代发。禁止编排层持有执行引擎长期凭证。变异工具仅控制面按游标签发的单步可调。工作台与操作计划共用同一执行引擎，不得另开 SSH 旁路。执行引擎不写策展/观测/冲突表。
4. **步骤断言**：已审计划每步含对工具结构化结果的预先声明约定；成败由执行引擎判定。禁止由模型阅读输出决定本步对错或发出下一次调用。失败即停、计划作废；编排层用全程逐步记录做失败分析并起草新人审计划。成功路径上编排层不 function call。
5. **诊断取证**：B-live 只读工具经控制面代发、由执行引擎执行。次数、对象范围（诊断子图）、超时由控制面强制封顶；超限则诊断失败并列出所需材料（与 ADR-0030 扩图封顶同类）。读结果不写观测/策展。
6. **模型出站**：HTTPS 白名单与密钥在 AI 编排层（仍禁止任意外网；载荷不得含业务库/客户/订单/财务）。控制面不持模型密钥、不直连 LLM。控制面不得把业务敏感内容塞进派给编排层的作业包。编排主干禁止 LangChain 类框架（ADR-0043 Forbid 不变）。
7. **编排层不可用**：控制面规则分叉仍须兜底，不得因无模型/无编排层而挡住警告、选支、人审、执行（承接 ADR-0041）。
8. **能力 vs 权力**：扩大资料与规划词汇；不扩大执行期可自行调用的变异面。权限白名单仍为人批，不得由编排层自写。

## 考虑过而拒绝的

- 执行期 AI 当序列器、按 function call 发下一步：与计划冻结、模型不可用仍须能执行冲突。
- 模型阅读日志判定本步成败：隐藏的改步/重试。
- 编排层短时令牌直连执行引擎：调用更短，但执行引擎成为第二入口，解耦失败。
- 整份冻结计划交给执行引擎内跑完：空洞/升级无法立刻从权力中心作废在途步骤。
- 工作台留在控制面自己 SSH：两条现场通道即旁路。
- 控制面进程内 WebClient 加料诊断文案：密钥落在权力中心，且把编排层做成装饰。

## 后果

- 交付形态变为：`archops:latest`（控制面+前端静态）+ **执行引擎** + **AI 编排层** + postgres + redis；Host Agent 仍不进控制面默认 Compose。拆这两进程不再是 Later。
- MINA SSHD 与主机凭证从控制面迁到执行引擎；计划互斥锁仍由控制面在下发前加。
- 竖切已闭合的 HTTP 闭环（规则诊断兜底、人审、fake/MINA 执行）在编排层未交付前必须继续可跑。
- **现码偏离，必须重写，禁止在偏离上继续加功能**：
  - 控制面 `DiagnosisLlmClient` + `AiEgress*` + 进程内 WebClient 出站（密钥在控制面）→ 删除；出站只属于编排层。
  - 控制面 `MinaSshPort` / `ControlledSshPort` 作为生产动手路径 → 迁到执行引擎进程；控制面只保留对执行引擎的代发客户端。过渡期测试 fake 可留在控制面适配器，不得扩大生产直连 SSH。
  - 诊断仅规则引擎、无 B-live 代发、无步骤断言、无逐步事件给编排层 → 随编排层/执行引擎交付补齐，不在未绑定票 05 里顺手做。
- 实现拆分须另开工单与 TDD，**不要写入** `.scratch/unbound-identity-rebind/` 票 05–09。
