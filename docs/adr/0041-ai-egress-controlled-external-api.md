# AI 出站：受控调用外部 OpenAI 兼容 API

控制面位于运维隔离区，但当前无自建模型，仅使用 DeepSeek、ChatGPT 等外部 API。采用受控出站：只允许访问配置白名单中的模型 HTTPS 端点（OpenAI 兼容）；禁止任意外网。出站载荷不得包含业务库内容或订单/客户/财务等数据；允许的至多是诊断子图摘要、冲突元数据、非机密标签与计划/草案文本。竖切 MVP 在模型不可用时可规则分叉兜底，不得因无模型而无法发出冲突警告或完成人工选支/人审执行闭环。区内自建模型留作将来可选，不作为当前前提。

**ADR-0044**：密钥与出站白名单在 **AI 编排层**（运维隔离区内），控制面不持模型密钥、不直连 LLM。白名单/禁载荷/规则兜底纪律不变。
